### 🔷 SnipVault — Code Snippet Library
Full-stack snippet manager with 39+ snippets across languages, admin mode, syntax highlighting, and Supabase backend. Deployed on Netlify.  
`HTML/CSS/JS` `Supabase` `Netlify` `Git`

---

### 🔷 AcadNex — Study Planner & Pomodoro
Built in two forms: a Vue.js study planner and a Flutter Pomodoro app. Flutter version uses Provider, SharedPreferences, and flutter_animate. Designed in Figma first.  
`Flutter` `Vue 3` `Provider` `Figma`

---

### 🔷 DSA Visualizer — Algorithms in Motion
Animated sorting algorithms (Bubble, Merge, Quick) + Stack, Queue, and Linked List visualizations. Originally prototyped, now being rewritten as a proper Vue 3 project.  
`Vue 3` `Vite` `Tailwind` `GSAP`

---

### 🔷 Budget Tracker — Flutter + Firebase
Mobile budget tracker with Firestore integration, category breakdowns, and budget alert thresholds.  
`Flutter` `Firebase` `Firestore`

---

### 🔷 AI Journal — Desktop App
Desktop journaling app powered by OpenRouter (Mistral). Built with Tkinter + SQLite. AI-assisted reflection and mood tracking.  
`Python` `Tkinter` `SQLite` `OpenRouter`

---

### 🔷 Computer Vision Project
Face detection, object detection, and age/gender estimation on Google Colab using OpenCV, YOLOv8, and DeepFace.  
`Python` `OpenCV` `YOLOv8` `DeepFace` `Google Colab`
